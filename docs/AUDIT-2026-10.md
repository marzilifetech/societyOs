# Audit — October 2026 (staff app, notifications, backend, admin web)

Started 2026-10-11. Scope, in the owner's order: **staff app first** (it crashes on
open), then notifications end to end, then the admin web portal, then the
resident app. Every row was found by reading code, and is re-verified against
the code before it is fixed. Status: `todo` · `fixed` · `wontfix (reason)` ·
`needs owner`.

How the production build was checked: the Play AAB 1.0.5 (8) from 2026-09-04
was installed on an Android 16 emulator. Signed-out launch works. A signed-in
session could not be reproduced on device (the only bypass login on production
is a resident), so signed-in fixes are covered by unit tests; on-device
verification needs a staff test login.
